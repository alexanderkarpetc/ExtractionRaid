# Road Builder

Відкрити **Tools → Level Design → Road Builder**. Інтерфейс англійською.

1. Зберегти звичайну сцену. Земля повинна мати Collider або TerrainCollider.
2. Натиснути **Create New Road**. Увімкнений **Place Points (Left Click)**:
   кліками по землі прокласти дорогу щонайменше двома точками. Alt залишає навігацію камерою.
3. Вимкнути Place Points, вибрати сферу точки та пересунути її через position handle.
   **Remove Selected Point / Remove Last Point** видаляють точки. Зміни підтримують Undo/Redo.
4. Задати **Width**, **Sample Spacing**, **Smooth**, **Width Segments**.
   Smooth використовує centripetal Catmull–Rom між точками; ширина та крок задані в метрах.
5. **Snap To Ground** притискає центр і всі поперечні вершини до Collider-ів у **Ground Layers**.
   **Ray Height / Ray Distance** визначають вертикальне сканування. **Surface Lift** піднімає
   дорогу над поверхнею, **Depth Offset** допомагає при накладанні геометрії.
6. За потреби призначити **Material Template** із шейдером `ExtractShaders/SplatRGBA`
   та налаштованими текстурами. Шаблон копіюється; кожна дорога має власний матеріал.
   Без шаблону матеріал створюється білим: після генерації призначити йому текстури шарів.
7. **Texture Tile Size** задає базовий розмір повторення текстур у метрах. Текстури шарів
   повинні мати **Wrap Mode → Repeat**. Tiling кожного шару в матеріалі додатково змінює масштаб.
8. **Initial Map Resolution / Edge Fade / Fade Ends** визначають лише початкові карти.
   Edge Fade задається в метрах; Fade Ends додає згасання на початку та кінці дороги.
9. **Build Road and Create Paint Maps** просить місце в Assets та створює окрему папку:
   меш, матеріал, `Splat.png` із основним шаром R та `Mask.png` із плавними краями.
10. **Open Splat Map Painter** відкриває Painter із цією моделлю. Вибрати Splat або
    Visibility Mask та **Edit Map from Material**. Малювати і зберігати як описано в
    [інструкції Painter](splat-map-painter.md).

## Налаштування

### Геометрія та поверхня

| Поле | Значення |
|---|---|
| **Width** | Ширина дороги в метрах. |
| **Sample Spacing** | Крок вибірки вздовж дороги. Менше значення дає більше вершин, плавніші повороти та краще повторення рельєфу. |
| **Smooth** | Згладжує шлях між контрольними точками. Без нього шлях складається з прямих відрізків. |
| **Width Segments** | Кількість поділів упоперек дороги. Збільшувати, якщо земля нерівна по ширині; це збільшує кількість полігонів. |
| **Snap To Ground** | Притискає центр і поперечні вершини до поверхонь із колайдерами. |
| **Ground Layers** | Шари, які вважаються землею. Використовуються для розставлення точок і притискання меша. |
| **Ray Height** | Висота над перевірюваною позицією, з якої починається пошук землі вниз. |
| **Ray Distance** | Повна довжина пошуку вниз, включно з Ray Height. Наприклад, Height 10 і Distance 30 охоплюють приблизно 20 метрів нижче перевірюваної позиції. |
| **Surface Lift** | Фізичне підняття меша над землею в метрах. Наприклад, 0.02 — це 2 см. |
| **Depth Offset** | Зміщення глибини під час відображення, без переміщення вершин. 0 вимикає його; від’ємне значення допомагає при накладанні на землю. |

### Матеріал і карти

| Поле | Значення |
|---|---|
| **Texture Tile Size** | Базовий розмір повторення текстур у метрах. Менше значення — частіше повторення. Tiling окремого шару в матеріалі додатково змінює масштаб. |
| **Material Template** | Splat-матеріал, який копіюється при першому створенні дороги. Подальші зміни шаблону не оновлюють уже створену копію автоматично. |
| **Initial Map Resolution** | Роздільність початкових Splat і Mask PNG. Вища роздільність дозволяє точніше фарбувати, але потребує більше пам’яті. |
| **Edge Fade** | Ширина початкового плавного згасання бокових країв у метрах. Наприклад, 0.25 — перехід на 25 см. |
| **Fade Ends** | Додає згасання тієї самої ширини на початку та кінці дороги. |

**Initial Map Resolution, Edge Fade та Fade Ends застосовуються лише при першому створенні
карт.** Rebuild не перезаписує намальовані PNG. Щоб змінити краї існуючої дороги,
редагувати Visibility Mask у Painter. Material Template також використовується лише
при створенні матеріалу; текстури готової дороги змінювати у її власному матеріалі.

Приклад стартових налаштувань: Width 4, Sample Spacing 0.5, Width Segments 4,
Surface Lift 0.02, Texture Tile Size 2, Depth Offset -1, Initial Map Resolution 1024.
Це приклад для звичайної дороги, а не універсальні значення для будь-якого рельєфу.

## Переміщення точок маніпулятором

1. Вимкнути **Place Points (Left Click)**.
2. Увімкнути **Edit Points in Scene View**.
3. Натиснути на сферу потрібної точки — з’явиться маніпулятор переміщення.
4. Перетягнути точку. При ввімкненому Snap To Ground інструмент намагається повернути її на землю.
5. Натиснути **Rebuild Road**, щоб оновити меш.

Якщо маніпулятор не з’являється, перевірити обидва перемикачі вище, вийти з Play/Prefab Mode
і закрити Splat Painter після збереження карти цієї дороги.

## Збереження та редагування

Точки й налаштування зберігаються в компоненті `SplatRoad` у сцені. Меш та матеріал —
окремі assets, тому згенерована дорога відображається після закриття інструмента і в білді.
Генерація виконується тільки кнопкою; після переміщення точок треба **Rebuild Road**.
Колайдер на дорогу автоматично не додається — це візуальна поверхня над існуючою землею.
Дублікати сценового об’єкта зберігають спільні mesh/material assets. Щоб не перебудувати
меш іншого екземпляра, генератор блокує таку перебудову; для незалежної дороги використати
Create New Road. Спільні дороги можна залишити як повторювані екземпляри без перебудови.

Rebuild зберігає намальовані PNG. При зміні форми, ширини або довжини їхні ділянки можуть
зміщуватися чи розтягуватися: UV0 нормалізовані на всю дорогу. **Texture Tile Size**
змінює лише повторення шарів і не змінює координати карт малювання.
Перед перебудовою зберегти карти й закрити Painter; інструмент блокує редагування та
перебудову, поки Painter тримає відкриту карту цього renderer-а.

Undo точок не перебудовує меш автоматично. Undo генерації відновлює прив’язки/геометрію,
але створені asset-файли залишаються на диску. Збереження PNG у Painter не скасовується
через Undo. Scene та намальовані PNG слід зберігати окремо.

## Межі застосування

Підтримуються відкриті дороги з 2–256 точками. T/X-вузли створюються окремою командою нижче. Замкнуті кільця, довільні автоматичні перехрестя,
бордюри та вузли з’єднання не генеруються. Дуже різкі повороти, самоперетини або ширина,
що перевищує радіус повороту, можуть накладати трикутники: розсунути точки, звузити дорогу
або розділити її на секції. Довгі дороги варто ділити на секції також для деталізації фарби.

Для нерівної землі зменшити Sample Spacing та збільшити Width Segments. Якщо земля не
знайдена хоча б під однією вершиною, генерація завершується повідомленням, без плаваючих
ділянок. На багаторівневих поверхнях звузити Ground Layers і діапазон вертикального raycast.
Райкасти ігнорують компоненти доріг, triggers та тимчасові колайдери Painter.

UV0 — унікальні 0–1 для Splat і Mask. UV3 (канал із індексом 3) — координати повторення
шарів, які читає **Use Road Detail UV (UV3)** у шейдері; генератор вмикає його автоматично.
Звичайні меші без цього перемикача продовжують використовувати UV0 для всіх текстур.
Прозорість, тіні й сортування мають ті самі правила, що в Splat Painter.

## Розмітка поверх готової дороги

1. Виберіть вихідну дорогу у Road Builder і натисніть **Create Overlay from Current Path**.
2. Інструмент створить окремий об’єкт Markings, скопіює точки та налаштування геометрії.
   **Surface Lift** буде на 0.01 м більшим, ніж у вихідної дороги.
3. Залиште **Use Splat Maps** вимкненим. У **Material Template** призначте матеріал
   із шейдером ExtractionRaid/Road Marking Unlit і текстурою розмітки з прозорим фоном.
4. **Width** задає ширину смуги меша. UV0 охоплює текстуру один раз поперек ширини;
   **Texture Tile Size** задає довжину одного повтору вздовж дороги в метрах.
   Для повторення задайте текстурі Wrap Mode **Repeat**.
5. Натисніть **Build Mesh** і виберіть місце збереження. Створяться власні mesh і material,
   без Splat/Mask PNG. Після першої побудови редагуйте створений матеріал у Mesh Renderer;
   Material Template застосовується тільки при першому створенні.
6. Після зміни точок або ширини натисніть **Rebuild Mesh**.

Це незалежна копія траси: зміни вихідної дороги не синхронізуються з розміткою.
Вихідні меш, матеріал і карти не змінюються. Створення об’єкта підтримує Undo.
Режим **Use Splat Maps** обирається до першої побудови; для іншого режиму створіть новий шар.
Його можна ввімкнути і для копії траси, якщо потрібен другий шар саме для Splat Painter.

Grounding повторно використовує колайдери землі. На нерівній поверхні при іншій ширині
перевірте накладання вручну: сітки з різною шириною можуть по-різному апроксимувати рельєф.
За потреби підкоригуйте Surface Lift, Sample Spacing і Width Segments.
## Бокове зміщення розмітки

**Lateral Offset (m)** зміщує меш уздовж поперечного напрямку траси: додатне значення
праворуч, від'ємне ліворуч за порядком точок. Контрольні точки й маніпулятори залишаються
на початковій трасі. Після зміни натисніть **Rebuild Mesh** (або Build Mesh для нового шару).

Для дороги шириною 4 м і розмітки шириною 0.2 м задайте **+1.9** або **-1.9**:
зовнішній край розмітки збігатиметься з краєм дороги. Для відступу 0.1 м від краю
використайте **+1.8** або **-1.8**. Якщо вихідна дорога вже має offset, додайте його
до цих значень. Create Overlay from Current Path копіює поточний offset.

Зміщення застосовується до кожного поперечного ряду меша, тому враховує повороти.
Grounding виконується в нових позиціях вершин. Повторення текстури вздовж траси
залишається прив'язаним до довжини початкової центральної лінії.
На різких поворотах великий offset може створити самоперетини; перевіряйте результат.
## Т- і Х-перехрестя

1. Підготуйте **3 окремі дороги для Т-вузла** або **4 для Х-вузла**. Кожна дорога має
   закінчуватися біля спільного центру. Наскрізну дорогу потрібно заздалегідь зробити
   двома окремими підходами. Побудуйте кожну дорогу через Build Road.
2. Збережіть карти та закрийте Painter для всіх підходів.
3. Виділіть 3 або 4 об’єкти доріг у Hierarchy. У Road Builder натисніть
   **Create Intersection from Selected Roads** (також є в Tools → Level Design).
4. На новому об’єкті перевірте **Approaches**: **Start** означає першу точку дороги,
   вимкнений Start — останню. Інструмент початково обирає найближчу групу кінців.
5. Налаштуйте параметри й натисніть **Build / Rebuild Intersection** в Inspector.
   Першого разу виберіть місце для окремої папки mesh/material/Splat/Mask.
6. Центральне покриття можна фарбувати кнопкою **Open Splat Map Painter**.

| Параметр | Значення |
|---|---|
| Cutback | Відстань обрізання від вибраного кінця кожної дороги, у метрах уздовж траси. Обрізання округлюється до найближчого наступного ряду меша. |
| Corner Rounding | Форма сполучення між підходами: 0 — прямий скіс, 1 — квадратичне заокруглення до внутрішнього кута. Це не радіус у метрах. |
| Corner Segments | Кількість сегментів заокруглення. |
| Surface Segments | Кількість внутрішніх радіальних рядів для посадки центрального меша на рельєф. |
| Material Template | Джерело текстур SplatRGBA для першого створення матеріалу; початково взято з однієї дороги. |
| Map Resolution | Розмір початкових карт самого перехрестя; при перебудові PNG зберігаються. |

Підходи повинні мати однакові **Snap To Ground**, **Ground Layers** і **Surface Lift**.
Для центрального меша raycast-параметри та Texture Tile Size беруться з першого підходу.
Якщо підходи перекриваються або кут складається, збільште Cutback чи випряміть
кінці доріг. Завеликий Cutback, який поглинає дорогу, блокує побудову.

Контрольні точки не видаляються. Обрізаються лише generated meshes; залишені вершини
зберігають початкові UV і намальовані карти. Центральна геометрія точно повторює вершини
кожного стику. Її текстури мають планарні світові UV, тому напрям текстури на стиках
може відрізнятися — переходи покриття налаштовуйте через Splat Painter.
Якщо на дорозі вже намальовано прозорість біля стику, відновіть її через **Show — White**.

Після зміни підключеної дороги перебудовуйте **все перехрестя**, а не дорогу окремо.
Road Builder має кнопку **Select Connected Intersection**.
Перебудова перехрестя перевіряє всі підходи до зміни assets і не перезаписує PNG.
Зміна самої траси, на відміну від простого обрізання, може пересунути фарбування.

**Detach and Restore Roads** відновлює повні меші доріг і вимикає Renderer вузла.
Assets зберігаються. Створення, побудова й від’єднання підтримують Undo;
створені файли залишаються на диску після Undo. Перед видаленням вузла спочатку
від’єднайте дороги; якщо вузол уже видалено, перебудуйте дороги окремо.

Обмеження: один вузол на об’єкт дороги — довгі дороги між вузлами діліть на секції.
Підтримуються відкриті наземні Т/Х-підходи, без автоматичного розрізання існуючих
наскрізних сплайнів, багаторівневих розв’язок, бордюрів і дорожньої розмітки.
Наявні overlay-об’єкти незалежні: їхня розмітка не обрізається разом з покриттям;
кінці розмітки приховуйте маскою. На складному рельєфі перевірте стики й збільште
Surface Segments за потреби. Сцени інструмент автоматично не зберігає.
