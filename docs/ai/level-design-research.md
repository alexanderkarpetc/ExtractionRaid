# Level Design Research — Top-Down Extraction Shooter

> Дослідження для першої карти ExtractionRaid. Квітень 2026.

---

## 1. Tarkov: Еталон Extraction Map Design

### 1.1 Customs — Чому це ідеальна стартова карта

- **Лінійний макролейаут**: витягнутий прямокутник, спавн на одному кінці → екстракт на протилежному
- **Cross-flow**: гравці з заходу йдуть на схід і навпаки — зустрічі в центрі гарантовані
- **Висока POI-щільність**: Dorms, Big Red, Construction, Old/New Gas Station, Checkpoint, RUAF, склади — завжди є щось поруч
- **Збалансовані відстані**: Dorms (головний POI) приблизно в центрі — однакова відстань з обох спавнів
- **Різноманітність боїв**: CQB (Dorms коридори), mid-range (двори, будівлі), long-range (міст, поля)
- **Навчання через квести**: перший квест відправляє на Customs → гравець вивчає карту природньо
- ~13 гравців, ~8-10 POI, ~8-10 екстрактів (гарантовані + умовні)

### 1.2 Ключові паттерни карт Tarkov

**Opposite-side extraction** — найкращий flow-механізм:
- Спавн на сході = екстракт на заході (і навпаки)
- Змушує перетнути всю карту → зустрічі неминучі
- Працює як "натуральний" pvp-механізм без штучних кіл

**Спавни**:
- Завжди по периметру карти, ніколи в центрі
- ~18-22 спавн-поінтів на Customs, рівномірно по сторонах
- Проблема: спавни іноді надто близько один до одного (50-100м) → фрустрація

**Екстракти — 3 типи**:
1. **Гарантовані** — завжди відкриті, на протилежному краю карти
2. **Умовні** — потрібні рублі/ключі/дії (нагороджують знання карти)
3. **Випадкові** — можуть бути/не бути активні (потрібно перевірити)

**Босси**:
- Арена відповідає стилю боса: снайпер = відкрита зона, CQB-бос = вузькі приміщення
- Reshala в Dorms (CQB), Shturman на пилорамі (mid-long range), Tagilla в паркінгу (тісно)
- Спавн ~30% шанс → невизначеність додає тензію

### 1.3 Антипаттерни Tarkov (чого уникати)

| Проблема | Приклад | Урок |
|----------|---------|------|
| Єдиний обов'язковий bottleneck | Original Customs bridge | Мінімум 2-3 альтернативних маршрути |
| Один домінуючий POI | Shoreline Resort (70%+ лута) | Розподіляти лут між кількома POI |
| Прямокутна карта з 2 стінками | Lighthouse — спавни передбачувані | Форма карти повинна давати варіативність |
| Порожні зони | Woods — неструктурований ліс | Кожна зона повинна мати мету |
| Нерівні відстані до лута | Shoreline — деякі спавни за 30с від Resort | Баланс відстаней від всіх спавнів |

## 2. Інші Extraction Shooters

### 2.1 Hunt: Showdown — Система конвергенції

**Compound system**: 16 іменованих компаундів на 1км², кожен з унікальним силуетом для орієнтації.

**Clue → Boss → Bounty pipeline** (золотий стандарт конвергенції):
1. Команди спавняться по краях (мін. 110м одна від одної)
2. Збирають підказки (clues) → звужується зона пошуку боса
3. Бос знайдений → banish (3 хв, видно ВСІМ на карті) → масова конвергенція
4. Bounty carrier — позиція видима іншим гравцям → переслідування до екстракту

**AI як шумова пастка**: гранти/іммолятори/вулики — не серйозна загроза, але гуки від бою з ними видають позицію гравця. AI = інформаційна зброя.

**12 гравців / 16 компаундів = ~0.75 гравця на компаунд** → атмосфера очікування та страху.

### 2.2 Dark and Darker — Вертикальна прогресія

- Модульна система кімнат (hand-crafted rooms, 5x5 grid)
- **Floor progression**: глибше = кращий лут, складніші моби, менше екстрактів
- **Death Swarm** замість кола (тематичний закриваючий механізм)
- Extraction ropes — один гравець за раз → тензія в командах

### 2.3 The Cycle: Frontier — Зони складності

- Карта розбита на **difficulty tiers** (1-5), чітко позначені
- Аірдроп розкриває позицію гравця → конвергенція
- Howlers — роумінг-моби між гніздами, непередбачувана загроза
- Bright Sands (стартова) — переважно tier 1-2, небезпечні зони далеко від спавнів

### 2.4 Arena Breakout — Найпростіший онбордінг

- **Level + gear value gating** для карт (Farm = lvl 1, Airport = lvl 25+)
- Farm (стартова): 9 спавнів, 8 екстрактів, маленька, зрозуміла
- Spawn-determines-extract: спавн на сході = екстракт на заході

### 2.5 ZERO Sievert — Прямий конкурент

- **Top-down extraction shooter**, піксельарт, 500k+ копій
- 6 карт з процедурними елементами (географія, лут, вороги, екстракти — рандомізовані)
- Карти — мікс зон (ліс + індустріальна + жилтова)
- PDA показує загальний лейаут, але не деталі → exploration tension

## 3. Top-Down Специфіка

### 3.1 Камера змінює ВСЕ

| FPS | Top-Down |
|-----|----------|
| Гравець бачить вузький viewport, відкриває простір поступово | Гравець бачить весь layout одразу |
| Вертикальність = головний інструмент | Вертикальності практично немає |
| Cover ховає від очей | Cover блокує снаряди (не інформацію, якщо немає FoW) |
| Орієнтація по далеких ландмарках | Орієнтація по формі кімнат і підлозі |
| Підлога, стіни, стеля рівнозначні | **Підлога = головна візуальна поверхня** |

### 3.2 Fog of War — Головний генератор тензії

**Без FoW** top-down карта = повністю "прочитана" → немає невизначеності.
**З FoW** кожний дверний отвір = інформаційний гейт, кожний кут = потенційна засідка.

FoW перетворює top-down шутер з аркади на тактичний досвід:
- Короткі коридори з поворотами > довгі прямі коридори
- Кімнати з кількома входами — страшні (не можеш контролювати всі двері)
- Вікна / часткові стіни = часткова інформація
- Звук стає критичним навігаційним інструментом

### 3.3 Метрики (все в "ширинах гравця")

| Елемент | Розмір | Примітки |
|---------|--------|----------|
| Мін. коридор | 2x | Тісно, тільки CQB |
| Комфортний коридор | 3-4x | Стандартна навігація |
| Мала кімната | 4-6x | CQB, 1-3 вороги |
| Середня кімната | 8-12x | Стандартна бойова арена |
| Велика кімната/арена | 16-24x | Потрібні cover-об'єкти |
| Cover-об'єкт | 1-2x шириною | Захищає одного гравця |
| Cover gap (відкрита пробіжка) | 2-4x | ~0.5-1 сек exposure |
| Дверний отвір | 1.5-2x | Один entity проходить |

### 3.4 Дистанції бою

| Категорія | Відстань (player widths) | Зброя |
|-----------|-------------------------|-------|
| CQB | 0-3 | Shotgun, melee |
| Close | 3-8 | Pistol, SMG |
| Medium | 8-20 | Rifle (sweet spot) |
| Long | 20-40 | Sniper / marksman |

Видима область екрана = 30-60 player widths → long-range = край-до-краю екрана.

### 3.5 Cover — обов'язковий в кожній бойовій зоні

**Без cover** top-down дегенерує в circle-strafing (біг по колу + стрільба назад).

Правила:
- Кожна бойова арена: мінімум 2 flanking routes по краях
- Mix full/half cover, wide/narrow
- Жодна позиція не повинна контролювати всю кімнату
- Cover вздовж стін + кілька freestanding об'єктів в центрі
- Коридорний cover: один об'єкт кожні 3-5 player widths

### 3.6 Навігація і Wayfinding

- **Підлога несе візуальну ідентичність**: різні матеріали/кольори для різних зон
- **Форми кімнат** = landmark-и (L-подібна, кругла, трикутна)
- **Мінімапа** в top-down = інтуїтивна (та ж перспектива)
- **Double-coding**: shape + color + sound (жодний сигнал не повинен бути єдиним)

Зональна ідентичність:
| Зона | Підлога | Об'єкти |
|------|---------|---------|
| Індустріальна | Сірий метал | Машинерія, труби |
| Житлова | Дерево/килим | Меблі |
| Медична | Білий/зелений | Ліжка, обладнання |
| Військова | Бетон | Мішки з піском, ящики |
| Природа | Земля/трава | Дерева (кола зверху) |

## 4. Теорія Level Design для Extraction

### 4.1 Пейсинг

**4 змінні**: threat, tension, tempo, movement impetus.
Крива інтенсивності повинна рости і падати — постійний хай = заціпеніння, постійний лоу = нудьга.

В extraction шутерах пейсинг **player-driven**:
- Вузькі коридори → spike тензії
- Відкриті поля з cover → sustained medium
- Safe rooms / стартові зони → relief
- Raid timer → макро-зростання тензії з часом

**Природній arc одного рейду:**
- Early: агресивний (нічого втрачати)
- Mid: пік тензії (лут накопичений, екстракт ще далеко)
- Late: обережний або відчайдушний (таймер тисне)

### 4.2 "Weenie" концепт (Disney)

Великий, видимий здалеку landmark що тягне гравця.
- Hunt: Showdown — кожний компаунд має унікальний силует (димарь цегельні, вежа)
- В top-down: великі, унікально-формовані структури видимі навіть через FoW
- Для нашої карти: кожна зона повинна мати "weenie" — visual anchor

### 4.3 Risk/Reward через географію

Техніки створення "high risk / high reward" зон:
- **Центральність**: цінний лут в географічному центрі (всі проходять через нього)
- **Exposure**: шлях до лута через відкритий простір
- **AI density**: біля цінного лута — більше/сильніших ботів (шум = маяк для інших гравців)
- **Environmental signals**: архітектура/освітлення комунікують "тут щось цінне"

### 4.4 Convergence — Як змусити гравців зустрітися

| Механізм | Приклад | Тип |
|----------|---------|-----|
| Opposite-side extract | Tarkov, Arena Breakout | Структурний (завжди працює) |
| Clue → Boss → Bounty | Hunt: Showdown | Об'єктний (funnel) |
| Airdrop / timed event | Vigor, Cycle | Event-based |
| Shrinking safe zone | DaD Death Swarm | Temporal pressure |
| Map density | Marathon — малі карти | Passive (density) |
| AI як шумова пастка | Hunt, Tarkov | Indirect |

**Щільність гравців (sweet spot)**:
- Hunt: 0.75 гравця/compound → dread & anticipation
- Tarkov Customs: ~1.3 гравця/POI → frequent encounters
- Marathon: ~2.5 гравця/location → constant action

### 4.5 Стартова карта — принципи

**MUST HAVE:**
1. Простий макролейаут (лінійний або м'яко-лінійний)
2. Opposite-side extraction (спавн → перетнути карту → екстракт)
3. 6-12 іменованих POI з різною ідентичністю
4. Баланс відстаней від спавнів до ключових зон
5. Мінімум 2-3 маршрути між будь-якими двома зонами
6. "Quiet zones" по краях для новачків
7. 1-2 "hot zones" з кращим лутом для ветеранів
8. Cover в КОЖНІЙ бойовій зоні
9. Environmental teaching (візуальні сигнали небезпеки/безпеки)

**AVOID:**
1. Єдиний bottleneck без альтернатив
2. Весь лут в одному місці
3. Симетричний layout (extraction maps = реальні місця)
4. Порожні зони без мети
5. Занадто великі відкриті простори без cover
6. Складна вертикальність на першій карті

### 4.6 Psychологія гравця

- **Loss aversion**: гравець з лутом стає обережнішим → обирає безпечніші маршрути
- **Gear fear**: зменшується з вивченням карти → map knowledge = прогресія
- **Когнітивна карта**: landmarks → routes → survey (повне розуміння)
- **Швидкість**: ARC Raiders зменшили speed на 60% після переходу на extraction — повільний рух робить traversal значущим

## 6. Топ-інсайти для ExtractionRaid

1. **FoW — наш суперпаувер.** В нас вже є fog of war → кожний дверний отвір = тензія. Це те, чого немає у FPS extraction shooters, і це фундаментально змінює дизайн.

2. **Opposite-side extraction — обов'язково.** Перевірений механізм від Tarkov до Arena Breakout. Змушує перетнути карту → зустрічі гарантовані.

3. **Doorways > rooms.** В top-down з FoW дверні отвори — це фундаментальна одиниця дизайну. Кількість і розташування дверей визначає encounter більше, ніж форма кімнати.

4. **Cover — не опціональний.** Без cover top-down combat = circle-strafe. Кожна бойова зона потребує mix cover types.

5. **AI як noise trap.** Бій з ботами = маяк що видає позицію. Боти охороняють лут не стільки фізично, скільки інформаційно.

6. **Підлога = головна поверхня.** Зональна ідентичність через матеріал/колір підлоги, не стін.

7. **Прості маршрути, складні рішення.** Стартова карта: 2-3 маршрути з різним risk/reward, а не лабіринт.

8. **ZERO Sievert — прямий референс.** Top-down extraction shooter з 500k+ копій. Вивчити його карти детальніше.
