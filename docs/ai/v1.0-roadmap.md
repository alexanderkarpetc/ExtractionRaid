# ExtractionRaid — v1.0 Development Roadmap

> Execution plan до v1.0. Компаньйон до [`release-scope.md`](./release-scope.md) (feature-map + gap analysis).
> Зафіксовані рішення живуть там (🔒). Створено 2026-07-18 · звірено з репо 2026-08-05.
>
> **Обсяг (легенда):** S ≤ ~1 сесія · M кілька сесій · L ~1–2 тижні · XL багатотижнево / потребує ассетів.
> **Статус задачі:** ⬜ not started · 🔄 in progress · ✅ done.

## Зафіксований scope (summary)
- **Ціль = повний v1.0.**
- **Weapon Builder = headline** → **3×4 архетипи** (+Rocket payload, +Rotary delivery) + **3–4 exotics** + balance + Builder UX. Повна 4×5 = стретч.
- **Progression — node-based скіл-древо — IN** (рішення 2026-07-21, змінює попереднє OUT). Каркас готовий (UI + config-SO + persist, allocate-only); лишається wiring ефектів + джерело поінтів + баланс — задачі M2.7 / M2.8 + M4.4. Див. `progression.md`.
- **Мапи = 2 ігрові + бункер** (зараз 1 ігрова → треба +1).
- **Туторіал — окремого немає; перші квести = онбординг.** Квести розмазані на весь геймплей.
- **Іконки предметів = must-have** (генеровані — немає UI-артиста).
- **Локалізація = EN-only.**
- Attachments + модульне 3D + композиція — база, лишаються в будь-якому разі.

## M1 — Honest core loop

| # | Задача | Обсяг | Статус | Нотатки |
|---|---|---|---|---|

Deferred: secure-container, save-on-death. Плюс онбординг-батч (#61 quest marker, #62 deploy wayfinding + first-quest gate) — деталі в `handoff.md`. |

Тюнінг: `Dev Cheats → ⏱ Raid clock`; per-map авторинг — разом з мапою #2 (M3.1). HUD: `MM:SS` угорі по центру, стани warn/critical; екран смерті по таймауту каже «TIME'S UP». Таймаут ігнорує GodMode (вимикач = тривалість 0). 7 тестів у `RaidTimerSystemTests`. |
| M1.3 | Extraction UX (маркери / стани / кілька виходів) | S–M | ⬜ | читабельність extract, «extraction available» |

## Sequencing
1. **M1 перший** — робить гру «чесною» швидко, мінімальний ризик.
2. **Аудіо** — M1 (каркас) → M2 (повнота).
3. **Builder-контент** — hook-система (M2.2) перед exotic-контентом; нові cores (M2.3) можуть паралельно.
4. **Контент (M3)** — найдовший; blockout мапи #2 можна почати паралельно з M2.

## Ще не вирішене (розкрити по ходу)
- Secure container / insurance — дизайн-компаньйон до gear-loss (M1.1).
- Глибина enemy/loot-контенту на мапу (M3.6).
- Музична спрямованість / джерело ассетів (M2.1).
- Глибина economy (loyalty/reputation торгівців?) (M3.3).
