`Assets/Shaders/VibeCharacterShader.shader` (~330 LOC, hand-written URP):

- Replicates legacy `ExtractShaders/MainBase` features (`_Texture`, `_Saturate`, `_Color2`, `_ColorStreng`, `_UseAlpha`, `_ColorEmission`, `_BrightnessEmission`) with same property names → 3 character materials swapped via shader GUID without value re-authoring

- Added: rim flash + bullet decals via MaterialPropertyBlock (per-renderer overrides)
- Environment materials (4 crates) untouched — still on Amplify shader

### Hit feedback — rim flash + bullet decals

`Assets/Scripts/View/CharacterHitFx.cs` — lives on `CharacterBody.prefab`, survives ragdoll detach:
- **Rim flash**: fresnel `1-dot(N,V)`, fades over `Duration`, color picked per hit type (normal/headshot/kill/ricochet)
- **Bullet decals**: per-bone tracking (closest skeleton bone at hit → store local-space → re-transform per-frame). Decals follow live animation AND ragdoll physics. Ring buffer 8 entries з `DecalLifetime` decay
- BotView + PlayerView delegate to `CharacterHitFx`
- BotPresenter + PlayerPresenter route `EntityHit` events
- Y offset/jitter (`DecalYOffset = -0.25f`, `DecalYJitter = 0.1f`) — moves decals from face-level to belly area з spread
- Decal coverage bug fixed (dark colors були невидимі — used albedo lerp by coverage не by luminance, dropped emission contribution)

### Tau cannon mechanic + laser burst

**Charge-up (HL Tau style):**
- `WeaponStateMachineSystem.Charging`: removed cancel-on-release. ShootingSystem owns fire-on-release path
- `ShootingSystem`: AttackJustReleased while Charging → fires at `chargeRatio = clamp((elapsed - chargeStartTime) / chargeTime, 0, 1)`
- Damage: `damage *= lerp(0.3, 1.0, chargeRatio)` — quick tap = 30%, full hold = 100%
- Holding past max charge keeps weapon у Charging (no auto-fire)

**Laser rifle burst (laser + Auto delivery):**
- New `WeaponPhase.Bursting`
- After release-fire, `burstCount = round(lerp(1, 6, chargeRatio))` — quick tap = 1 shot, full hold = 6
- `ShootingSystem.TickBurst` fires next shot every `LaserBurstInterval = 0.07s`
- Each burst shot recomputes muzzle/aim (tracks rotation), uses cached `BurstChargeRatio`
- WeaponEntityState fields: `BurstShotsRemaining`, `BurstChargeRatio`, `LastBurstShotTime`
- Out of ammo mid-burst → Cooldown. Swap during burst → Unequipping

**Tests updated:** old "auto-fire on full charge" tests → "stays Charging until release"; old "cancel on release" → "release fires partial-charge shot".

### BeamFlashPresenter — Tau-style beam flash

`Assets/Scripts/View/BeamFlashPresenter.cs`:
- Listens `ProjectileSpawned` filtered by archetype `"Laser"` (per-pellet — laser shotgun gets 7 beams)
- Spawns LineRenderer GO from muzzle до forward raycast endpoint (default 60m)
- 10-vertex jagged path з sin envelope + per-frame re-randomization (electric flicker)
- Material `Vfx/Materials/VfxBeamFlash.mat` (Legacy Particles/Additive)
- All visual params scale with chargeRatio: lifetime 0.05-0.13s, width 0.06-0.28m, jagged amp 0.04-0.22m, color brightness 50-100%
- Wired у `App.LateTick` після CasingEjector
